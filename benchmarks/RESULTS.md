# Held-out evaluation

Generated by `pnpm eval` (benchmarks/evaluate.ts). Do not edit by hand.

Rules are learned from `baseline.har` (the 15 requests from `pnpm demo`) and tested on
`holdout.json`: 24 labelled requests (12 benign, 12 malicious) that the learner never saw,
sent through a running gateway in front of a real app. A malicious request is **caught** if it
never reaches the app. A benign request is a **false positive** if it doesn't reach the app.

This is a small, hand-labelled set. It shows behaviour and failure cases; it is not a
statistical accuracy claim.
